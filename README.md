# Explainable Brain Tumor Classification using EfficientNetV2 with Multi-Head Attention and Grad-CAM

Hybrid deep learning framework for four-class brain tumor MRI classification (glioma, meningioma, pituitary, no tumor) combining an EfficientNetV2-S backbone with a multi-head self-attention refinement module, trained via a three-phase progressive unfreezing strategy. Grad-CAM is used for spatial interpretability.

## Results

- Accuracy: 99.24%
- Weighted F1-score: 0.99
- Parameters: ~20.3M
